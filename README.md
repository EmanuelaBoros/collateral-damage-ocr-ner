# Collateral Damage: How OCR Errors Spread Through the Features of NER Models

**Work in progress.** This repository accompanies a paper that is currently under review. The code and documentation will be released here after the review process.

## About

The project studies how OCR errors affect named entity recognition (NER) models from the inside, on historical newspapers and scanned administrative forms.
